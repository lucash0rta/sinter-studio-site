# Sinter Studio Meeting Outline

## 1. Immediate Website / Showreel Priorities

### Core Question

What order should the showreel use so potential clients understand the range quickly, even if they do not watch the full reel?

### Notes

- Clients may not watch the whole showreel, so the first sections need to capture attention quickly.
- The first two topics should communicate the strongest value immediately.
- The reel should not feel like mixed fragments; it should show focused sections one at a time.
- Sectioning the reel could help clients notice the diversity of work rather than overlooking it.
- Avoid over-explaining client names or skill categories directly inside the reel unless it clearly helps comprehension.
- Website copy can stay minimal while the reel carries most of the expressive and capability-based work.

### Possible Showreel Structure

1. Strongest visual hook / most immediately impressive work.
2. Core studio capability section.
3. 3D / asset / simulation work.
4. Animation / video production / motion systems.
5. Closing identity card / contact prompt.

### Open Question

Do we want the reel organized by skill type, project type, client type, or emotional impact?

## 3. Brand Strategy Work Before Overbuilding

### Core Task

Do the brand thinking before committing too deeply to the website, reel, or logo.

### Research Questions

- Which references do we like?
- Why are those references good?
- What specifically relates to Sinter Studio?
- How do the references connect to our design ethos, ideology, or approach?
- What principles can we extract from the references?
- What should the brand convey emotionally and strategically?
- Who are we trying to reach?
- What is the target client’s tone, vibe, and expectation?

### Suggested Process

1. Gather references.
2. Explain why each reference works.
3. Identify shared visual or strategic traits.
4. Turn those traits into design principles.
5. Build a small brand kit.
6. Build a small motion kit.
7. Apply both to the showreel and website.
8. Get external designer feedback once there is a draft.

## 4. Brand Kit Direction

### Deliverable

A concise PDF brand kit that documents how Sinter Studio should look and behave visually.

### Possible Contents

- Logo
- Wordmark
- Typefaces
- Colour system
- Border / grid system
- Spacing rules
- Photography / video treatment
- Layout examples
- Website application
- Social / reel title-card examples

### Early Principles

- Use hard edges, not capsules.
- Prefer 1px borders.
- Dotted borders can be part of the web language.
- Avoid generic agency styling.
- Avoid AI-looking “slop.”
- Keep the work human-led and visually precise.

## 5. Motion Kit Direction

### Rationale

The brand should not only have static identity rules; it should also define how it moves.

### Possible Contents

- Motion descriptors, e.g. precise, abrupt, liquid, restrained, technical.
- Preferred animation curves.
- Rules for reveals, cuts, transitions, loops, bounces, and stops.
- Logo animation behavior.
- Reel title-card motion.
- UI motion for website interactions.

### Reference Mentioned

IBM Design Language was discussed as a strong reference for how a large brand explains philosophy, type, motion, and the relationship between humanity and technology.

## 6. Logo Direction

### Ideas Discussed

- A small cube / square-based logo.
- A grid structure that can be cut through the centre.
- Lines of different sizes that could move through time.
- A mark that may imply an “S” without being too literal.
- Combining a Chinese character-like structure with an English title style.
- Potentially using two or three square/rectangle blocks.
- A longer block version for the website.

### Why This Direction Seems Useful

- It connects to the definition of “sinter”: pieces joining together under pressure/heat.
- It can feel non-linear and all-at-once rather than a simple lettermark.
- It can work as both static logo and motion system.
- It can become a modular visual language for borders, grids, and title cards.

### Draft Direction

Use a square grid monogram as a rough starting point, then develop:

- Static mark.
- Wordmark lockup.
- Animated line / grid version.
- Website header version.
- Reel title-card version.

## 7. AI Positioning

### Core Thought

AI can be part of the studio’s working method, but the positioning should be careful. It should not sound like generic “AI-driven” marketing or imply low-quality automated output.

### Notes

- Businesses are increasingly expecting faster turnaround because of AI tooling.
- Some established design businesses are cautious or defensive about AI.
- There may be market value in being a young studio that can work quickly while maintaining taste and care.
- The key point is not “AI makes the work,” but that the studio uses AI selectively as part of a considered workflow.
- The work should remain human-led, relationship-led, and quality-led.
- AI can accelerate research, architecture, prototyping, and implementation.
- Avoid positioning that attracts only low-budget clients looking for cheap output.

### Possible Language Territory

- Human-led, tool-accelerated.
- Considered use of emerging tools.
- Fast workflows without sacrificing craft.
- Research-backed, design-led production.
- Selective automation where it improves process, not where it replaces judgment.

### Open Question

How visible should AI be in the public-facing brand language?

## 8. External Feedback

### Idea

### Purpose

- Avoid polishing the wrong thing too early.
